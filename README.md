# Petroguard

Petroguard is a fuel station management platform designed to help businesses manage operations, sales, and reporting.

## Features
- Dashboard for station monitoring
- Sales tracking
- User authentication
- Reports and analytics

## Tech Stack
- Next.js
- Supabase
- Vercel

## Setup
1. Clone the repo
2. Install dependencies
3. Add environment variables
4. Run the project

## Status
Work in progress (MVP)
